# Snck AI

Snck AI is a Snck-branded, self-hosted AI workspace built on LibreChat.

## One-command Ubuntu VPS install

Use the installer included in this repository to set up the Docker deployment on Ubuntu.

## Features

- Multi-provider AI chat
- Agents and MCP tools
- File and multimodal chat
- Code Interpreter workflows
- Web search
- Multi-user authentication
- Admin capabilities
- Docker deployment
- Ubuntu VPS installation

## Manual setup

Clone this repository, create your environment file from the provided example, and start the Docker Compose services.

## Security

Never commit API keys, passwords, tokens, or other secrets to GitHub. For production deployments, use HTTPS and a properly configured reverse proxy.
